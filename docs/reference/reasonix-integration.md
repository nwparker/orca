# Reasonix CLI evidence and integration boundary

Reasonix is the third-party esengine/DeepSeek-Reasonix product, separate from official DeepSeek Harness and innocarpe DeepSeek Build. This work targets stable npm `reasonix@1.39.7`, source tag v1.39.7 at `6dbabcbf7135c56ff5186b0cd36f5cc2725f47b4`. The repository default branch develops Studio 2.x; it is not the stable CLI contract.

The npm `bin/reasonix.js` wrapper selects an optional `@reasonix/cli-<platform>-<arch>` native `reasonix` executable. Orca's existing executable detection and native process observation apply on each execution host; the exact npm package path identifies its Node wrapper. Folder cwd works without Git. Old execution hosts do not advertise the new agent in their detection results.

Bare `reasonix`, `chat` and `code` are interactive. `-p`/`--print`, `run`, `serve`, `web`, `acp`, machine queries and configuration commands must not own a live interactive pane. A value such as `--model run` is not the run subcommand. Native interactive startup does not submit positional task text, so Orca sends the task through the established post-start PTY path. Existing cursor-after-bracketed-paste readiness recognizes the actual configured composer and withholds input from the missing-key connection menu. No account credentials or trust are written by this registry slice. Native unrestricted mode uses `--permission-mode danger-full-access`; deprecated `--yolo` does not establish that mode.

Actual isolated macOS arm64 PTY evidence reaches a composer, submits a harmless task to a task-only loopback provider, and receives SessionStart, UserPromptSubmit, Stop and SessionEnd with native camelCase payloads. The loopback response is a transport fixture, not paid/authenticated DeepSeek generation. Native `--resume <sessionId>` and `--continue` both replay the generated saved turn. These capabilities are observed; managed status/resume/history wiring is not yet claimed by the launch registry alone.

Current TUI persistence is `projects/<slug>/sessions-v4/<sessionId>/events.frames`, with manifest codec `reasonix.session.linear/v4`, RX4F frame headers, zstd records and referenced content. Machine `session list --json` still enumerates legacy sessions and returned an empty list for the generated current-format turn. A JSONL-only or machine-list-only scanner would lose history. Hooks load project/global settings.json and expose no alternate hook-config path flag. Managed status must reuse Orca's execution-host hook store while respecting the task's prohibition on global provider writes.

Raw readiness fixtures preserve terminal escapes/wrapping. Their metadata records source and release. Live Linux/Windows/SSH, real provider authentication, tools/approval and mobile device behavior have not been validated in this milestone.
