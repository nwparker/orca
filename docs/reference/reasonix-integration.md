# Reasonix CLI evidence and integration boundary

Reasonix is the third-party esengine/DeepSeek-Reasonix product, separate from official DeepSeek Harness and innocarpe DeepSeek Build. This work targets stable npm `reasonix@1.39.7`, source tag v1.39.7 at `6dbabcbf7135c56ff5186b0cd36f5cc2725f47b4`. The repository default branch develops Studio 2.x; it is not the stable CLI contract.

The npm `bin/reasonix.js` wrapper selects an optional `@reasonix/cli-<platform>-<arch>` native `reasonix` executable. Orca's existing executable detection and native process observation apply on each execution host; the exact npm package path identifies its Node wrapper. Folder cwd works without Git. Old execution hosts do not advertise the new agent in their detection results.

Bare `reasonix`, `chat` and `code` are interactive. `-p`/`--print`, `run`, `serve`, `web`, `acp`, machine queries and configuration commands must not own a live interactive pane. A value such as `--model run` is not the run subcommand. Native interactive startup does not submit positional task text, so Orca sends the task through the established post-start PTY path. Existing cursor-after-bracketed-paste readiness recognizes the actual configured composer and withholds input from the missing-key connection menu. No account credentials or trust are written by this registry slice. Native unrestricted mode uses `--permission-mode danger-full-access`; deprecated `--yolo` does not establish that mode.

Actual isolated macOS arm64 PTY evidence reaches a composer, submits a harmless task to a task-only loopback provider, and receives SessionStart, UserPromptSubmit, Stop and SessionEnd with native camelCase payloads. The loopback response is a transport fixture, not paid/authenticated DeepSeek generation. Native `--resume <sessionId>` and `--continue` both replay the generated saved turn. These capabilities are observed; managed status/resume/history wiring is not yet claimed by the launch registry alone.

Current TUI persistence is `projects/<slug>/sessions-v4/<sessionId>/events.frames`, with manifest codec `reasonix.session.linear/v4`, RX4F frame headers, zstd records and referenced content. Machine `session list --json` still enumerates legacy sessions and returned an empty list for the generated current-format turn. A JSONL-only or machine-list-only scanner would lose history. Hooks load project/global settings.json and expose no alternate hook-config path flag. Managed status must reuse Orca's execution-host hook store while respecting the task's prohibition on global provider writes.

Raw readiness fixtures preserve terminal escapes/wrapping. Their metadata records source and release. Live Linux/Windows/SSH, real provider authentication, tools/approval and mobile device behavior have not been validated in this milestone.

History reader work uses the stable binary's canonical `reasonix.session.linear/v4` log, not `session list --json` (which reads the legacy store and returned no rows for the actual saved turn). RX4F envelopes declare compressed/raw lengths in big endian, capped at 8 MiB; committed batches hash the original begin/event bytes followed by NUL. Incomplete append tails have no committed authority. Unknown required events fail closed, optional events remain forward compatible, and source/frame/batch budgets bound reads and retained data. The reviewed DSH Zstandard decoder is generalized with unchanged DSH limits and diagnostics; Reasonix supplies its tighter native limits. The actual isolated loopback binary's `events.frames` fixture and metadata preserve its source pin and artifact hash. These readers are not yet wired into the history registry, resume UI or remote capability contract.

Native current manifests identify sessions but do not encode cwd. Workspace directory names are lossy slugs, and explicit collision assignments use a `.workspace-root` marker. History/resume integration must read native project ownership or a supplied matching workspace; reverse-decoding a slug cannot establish cwd. `REASONIX_STATE_HOME` separates history storage from configuration, but copied `REASONIX_HOME` settings can silently fork native edits. Managed-hook injection remains unproven and must not rewrite global configuration or trust.

The bounded native projection now preserves message identity and order across completes, upserts, retractions and full history replacements. Model-context replacement and compaction do not erase saved visible chat. Content references must use lowercase SHA-256 identities, exact byte lengths and verified object hashes; each object is capped at 8 MiB, cumulative referenced content at 64 MiB, and cumulative decompressed framing at 64 MiB. A host-supplied reader owns filesystem access; the pure projection never accepts a reference-provided path. Project/workspace authority, renderer history and remote opt-in integration are still pending.

The decoder releases its transcript iterator before reading any referenced object. The execution-host filesystem limiter holds one slot for each transcript stream; awaiting a second read while eight streams hold all eight slots would deadlock. A deterministic failing-original/passing-candidate regression checks the source's `finally` block before the first content callback. Only visible-history events are retained during the bounded first pass, and replay clears consumed batch slots. The experimental `agent-session.reasonix-content-read-lifetime` reliability gate records this invariant, budgets and physical-provider/CI-soak gaps; it does not certify unimplemented history discovery or managed hooks.

Execution-host access now validates the actual revision-3 manifest and optional native Desktop header, bounds metadata to 64 KiB, refuses symlink/directory objects, and derives content filenames solely from verified SHA-256 identities. Both native fixed content locations are supported; arbitrary manifest roots and prototype revisions fail explicitly. The relay's existing byte reader accepts Reasonix only when explicitly requested and when the canonical session path starts with RX4F; ordinary binary reads remain refused. Actual fixture reads run through that host adapter. Missing CLI headers leave cwd unknown; no workspace is reconstructed from a slug. Parent lstat checks prevent stable symlink escapes, but Node does not provide the native Go `os.OpenRoot` lifetime guarantee against concurrent parent replacement; no equivalent race-containment claim is made.
